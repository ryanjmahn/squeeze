- Auto-wrap noisy commands through Claude Code hooks, so an agent that forgets `sq` still gets squeezed
- More squeezers: cargo, go test, gradle, docker build, eslint, ruff, mypy
- "Diff since last run": only show failures that are new or changed

- An MCP version, so agents can ask for a log at different detail levels
- Real token counting instead of characters ÷ 4
- Squeeze Wrapped: a year-end recap card
- Opt-in leaderboards with friends (numbers only)
- A GitHub Action that regenerates your profile card every week
